## 가상환경 생성
```
1. 가상환경 생성
conda create -n [가상환경 이름] python=[버전]
예: conda create -n bg-rec python=3.12

2. 가상환경 활성화
conda activate [가상환경 이름]
예: conda activate bg-rec

3. 라이브러리 설치
conda install -c conda-forge pandas numpy matplotlib scikit-learn
```
